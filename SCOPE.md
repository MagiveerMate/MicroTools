# V1 Release Scope

## Consumer app
Home/search, tool catalogue, tool detail, file selection, result/share workflow, history, optional account, usage limits, Pro entitlement, settings/privacy/support.

## Initial tools
PDF Compressor; PDF to Images; Image Compressor; Image Converter; QR Generator; VAT Calculator; URL Metadata Extractor.

## Backend
Gateway, processor adapters, temporary object storage, deletion lifecycle, usage metering, entitlement checks, structured logs, health checks, rate limiting.

## Store readiness
Apple/Google signing, privacy policy, store privacy/data-safety declarations, screenshots, icons, subscription products, beta tracks, review notes, release builds.

## Explicit V1 exclusions
On-device PDF/image engines, embedded ML models, advertising SDKs, social features, custom marketplace, arbitrary user code execution.
